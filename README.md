## Mục Tiêu Của Dự Án (Project Objectives)

- **Hiểu sâu bản chất**: Không chỉ dừng lại ở cú pháp (syntax), mà còn đi sâu vào cơ chế hoạt động, cơ chế quản lý bộ nhớ (memory management), concurrency model, và các mô hình lập trình (OOP, FP, Procedural).
- **So sánh & Đối chiếu**: Đánh giá điểm mạnh/yếu của từng ngôn ngữ đối với từng bài toán cụ thể (Ví dụ: Sự linh hoạt của JS vs Sự chặt chẽ của TS, Hiệu năng vượt trội của Rust vs Tốc độ phát triển thần tốc của Python).
- **Thực hành thực chất**: Mỗi ngôn ngữ sẽ đi kèm với các bài tập giải thuật (LeetCode, HackerRank), các mini projects thực hành thực tế, và rèn luyện tư duy viết mã sạch (Clean Code).

## Hướng Dẫn Trải Nghiệm (Getting Started)

Nếu bạn muốn tham khảo hoặc chạy thử các mã nguồn có sẵn trong phòng thí nghiệm này:

1. **Clone repository này về máy cá nhân:**

   ```bash
   git clone https://github.com/your-username/multi-lang-lab.git
   cd multi-lang-lab
   ```

2. **Khám phá từng thư mục:**
   Mỗi thư mục ngôn ngữ chính (như `javascript/`, `c++/`,...) đều có hướng dẫn cài đặt môi trường và các lệnh chạy chi tiết bên trong.
   ```bash
   cd javascript
   # Xem hướng dẫn cụ thể tại đó
   ```
